WHAT HAPPENS TO THE UE (answer)
------------------------------------------------------------------------
1. Not a permanent "disconnect from the network" (still registered).
2. Yes, a short AN release: AMF clears the OLD N2 leg on the legit gNB
   because it became stale after Holding/rebind → UE goes CM-IDLE (~0.5s).
3. UE self-heals with a normal Service Request → Service Accept; new AU=13.
4. User-plane: only ~5% loss in the continuous ping window; after recovery 0%.

Causal chain (important):
  Attacker's InitialUE → Holding → forged SR fails
  → legit gNB still has old AU → any UL NAS on stale context
  → AMF itself sends Release Command to legit gNB
  → UE Idle → UE Service Request recovers

So the UE impact is an AMF-driven stale-context cleanup, NOT the attacker
sending Release, and NOT a lasting PDU teardown.
